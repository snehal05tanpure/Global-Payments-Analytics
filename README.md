# Global Payments & Trade Analytics

## Project Overview

An end-to-end analytics portfolio focused on Global Payments & Trade operations, developed using a simulated banking transaction dataset.

The project demonstrates how data analytics and business intelligence tools can be used to monitor transaction performance, evaluate payment operations, identify exceptions and strengthen data quality controls.

## Project Objectives

- Monitor overall transaction volumes and business performance.
- Analyse payment processing efficiency and transaction statuses.
- Track SLA attainment and transaction failures.
- Identify data quality issues and exception patterns.
- Build interactive dashboards to support business decision-making.

## Technology Stack

- **Tableau:** Interactive dashboards and data visualisation.
- **Power BI:** Business intelligence reporting and data modelling.
- **SQL:** Data extraction, transformation and analysis.

## Tableau Dashboards

Three interactive dashboards have been developed:

### 1. Executive Overview
Provides a consolidated view of transaction volumes, completion rates, SLA attainment, transaction status and payment channel performance.

### 2. Payments Operations
Focuses on processing time, SLA performance, failed transactions, returned transactions and operational trends.

### 3. Data Quality & Controls
Highlights missing beneficiary information, invalid currencies, negative transaction amounts, repeated reference IDs and data quality patterns.
