# 🌐 Global Payments & Trade Analytics Dashboard

### 📊 End-to-End Data Analytics Portfolio Project | Power BI | Tableau | SQL

---

## 📌 1. Project Overview

This project focuses on analysing global payments and trade transaction data through an integrated Business Intelligence solution developed using Microsoft Power BI, Tableau and SQL.

The objective is to transform transactional data into meaningful business insights, enabling stakeholders to monitor payment performance, operational efficiency, service-level compliance and data quality.

The project uses a synthetic payments and trade dataset designed to simulate real-world banking transaction scenarios, including payment failures, processing delays, exceptions and data quality issues.

**Note:** All data used in this project is synthetic and does not represent actual BNY or customer information.

## 🎯 2. Project Objectives

The key objectives of this project are to:

- Monitor overall payment transaction volumes and completion rates.
- Analyse payment processing performance across different channels.
- Evaluate SLA attainment across geographical regions.
- Track failed and returned transactions.
- Monitor transaction processing time and operational efficiency.
- Identify data quality issues and exception trends.
- Detect missing, invalid and inconsistent transaction records.

## 📂 3. Dataset Description

The project uses a synthetic, multi-table dataset designed to represent a global payments and trade environment.

**Key data areas include:**

- Customer information and customer segments.
- Payment transactions and transaction status.
- Payment channels and geographical regions.
- Transaction dates, currencies and amounts.
- Processing hours and SLA indicators.
- Exception records and exception status.
- Data quality issues and recommended corrective actions.

The dataset supports data modelling, joins, aggregations, data quality analysis and business KPI reporting.
